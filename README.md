# 重慶六日遊 · 互動行程表

2026 年 10 月 9 日（週五）– 10 月 14 日（週三）· 香港出發

手機優先嘅圖文並茂互動行程表：每日 Tab 切換時間軸、17 張景點卡（真實照片，可展開開放時間／門票／貼士）、航班酒店資訊條。

## 本地預覽

```bash
npm install
npm run dev
```

或直接喺瀏覽器開 `index.html`（純靜態頁面，冇 build step）。

## 技術

- 單一 `index.html`，vanilla HTML/CSS/JS，零框架
- 圖片來源：Wikimedia Commons 及公開來源（載入失敗自動 fallback）
- 可選用 Vite 做 dev server（`npm run dev`）
